# v1.2.2 技能欄實作

依最新要求恢復功能：使用官方攤位每隻寵物的 Slot（兼容 slot）直接顯示。已於 2026-10-08 取得官方 136 隻樣本，Slot 分布為 6–10，同物種與不同升星配點可有不同值；不得使用 HaveSkillLimit 或已學技能數替代。

滿技條件與提供的範本一致：滿星 25 星，且目前 Slot 不低於圖鑑物種基準。圖鑑只作比較，不用來填入個體欄數。未知物種、無效或缺少 Slot 不通過滿技篩選。

官方市場前端目前只顯示圖片、名稱、等級與價格；沒有將它宣稱為官方滿技判定。此版採範本的滿技規則，並在介面明示條件。

通過 npm run check，包含 Slot 6–10、缺失/非法值、滿星但減欄、未滿星、未知物種、篩選併用與其他既有功能。
